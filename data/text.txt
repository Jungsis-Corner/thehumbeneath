# THE HUM BENEATH - all game strings
# One entry per line:  ID  text
# - the build turns ID into the assembler constant T_ID (src/textid.inc)
# - \n starts a new line, every line max. 40 characters
#   (%s counts as 12 characters, %d as 6)
# - ASCII only, placeholders: %s (name), %d (number), %% (percent sign)
# - "@width n" sets a smaller line width for the entries that follow
#   (the party panel shows 15 characters, names are at most 12)
# - "@digits n" sets the width of %d for the entries that follow (default 6,
#   enough for -32768); hit points, stats, XP and moss stay below 1000
# - "@strlen n" sets the width of %s for the entries that follow (default 12,
#   the longest cat name); enemy names may have 16 characters
